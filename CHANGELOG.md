# Изменения

## 0.3.1

- Исправлена проверка GitHub Actions: кеш зависимостей исключён из списка пакетов контроллера.

## 0.3.0

- До трёх попыток загрузки, раздельные ошибки DNS/TLS/HTTP/таймаута без вывода ссылок и секретов.
- Загрузка подписок напрямую или через работающий VPN, настраиваемый User-Agent.
- Белый и чёрный фильтр названий с регулярными выражениями, удаление дубликатов.
- Статистика обновления, безопасный перенос выбора при однозначном совпадении сервера, предупреждения об исчезнувших выбранных записях.
- Предыдущий список на диске и в памяти сохраняется при отказе применения нового списка.
- ChatGPT и Instagram: готовые проверяемые ядром `.srs`; при сетевом отказе используется последняя рабочая копия.
- Таймаут DNS, повтор отказавшего DNS, удержание выбранного и порядок резолверов.
- Отдельный UDP-пул и правила TCP/UDP. Проверки задержки используют HTTPS и не подтверждают доступность UDP.
- До 32 текущих соединений в «Обзоре», без служебных загрузок подписок.
- README, пошаговая инструкция и GitHub Actions обновлены для выпуска 0.3.0.
