# Изменения

## 0.4.0

Стабильность соединения:

- После любого перезапуска ядра сразу выбирается последний рабочий сервер, а не заглушка «нет сервера». Ещё не проверенные серверы после загрузки используются сразу.
- Серверы проверяются параллельно. Группа без рабочего сервера перепроверяется каждые 15 секунд: восстановление после сбоя занимает около 30 секунд вместо примерно 10 минут.
- Соединения на упавшем сервере закрываются, и программы сразу переподключаются через новый.
- Упавшее ядро сразу перезапускается с текущей конфигурацией, зависшее — принудительно через 30 секунд. Причина падения сохраняется в `/tmp/routerbox/core-error.log`, при нехватке памяти в событиях есть подсказка.
- Ежедневное обновление списков доменов подменяет файлы правил в работающем ядре без перезапуска. Неизменённые списки не пересобираются и не перезаписываются на flash.
- Подписка проверяется ядром пачками по 64 сервера: обновление больших подписок больше не блокирует переключение серверов на минуты.

Безопасность:

- Тексты в LuCI (адреса сайтов из соединений, имена серверов и подписок, ошибки) выводятся как текст, а не HTML. Раньше устройство в сети или провайдер подписки могли выполнить скрипт в сессии администратора.
- Импорт подписок отклоняет серверы, которые запускают программы на роутере (проверки хоста OpenConnect), читают его файлы или используют Tailscale. Привязка к интерфейсам роутера, системные интерфейсы и прослушиваемые порты из подписки удаляются. Уже сохранённые серверы проверяются повторно.
- Ссылка подписки с токеном больше не передаётся в LuCI: в панели виден только адрес сервера, а для замены ссылки достаточно ввести новую.
- Предупреждение для подписок по HTTP и серверов с отключённой проверкой TLS-сертификата.
- Установщик доверяет ключу пакетов RouterBox только на время установки. Ключ, оставленный предыдущими версиями в `/etc/apk/keys`, удаляется.

При первом применении настроек после обновления ядро перезапустится один раз: правила переезжают на постоянные пути.

## 0.3.3

- Вкладка «Обновление»: установленная/последняя версии, проверка GitHub Releases, доступность новой сборки и ссылки на выпуск.

## 0.3.2

- HWID подписок с приватным хранением, сохранением/удалением из LuCI и запретом передачи на другой сервер при перенаправлении.
- Импорт независимых VLESS-записей из Xray JSON, включая TLS/REALITY, WS, gRPC, XHTTP и XMUX.
- Служебные ответы «Устройство не поддерживается» больше не считаются серверами.

## 0.3.1

- Исправлена проверка GitHub Actions: кеш зависимостей исключён из списка пакетов контроллера.

## 0.3.0

- До трёх попыток загрузки, раздельные ошибки DNS/TLS/HTTP/таймаута без вывода ссылок и секретов.
- Загрузка подписок напрямую или через работающий VPN, настраиваемый User-Agent.
- Белый и чёрный фильтр названий с регулярными выражениями, удаление дубликатов.
- Статистика обновления, безопасный перенос выбора при однозначном совпадении сервера, предупреждения об исчезнувших выбранных записях.
- Предыдущий список на диске и в памяти сохраняется при отказе применения нового списка.
- ChatGPT и Instagram: готовые проверяемые ядром `.srs`; при сетевом отказе используется последняя рабочая копия.
- Таймаут DNS, повтор отказавшего DNS, удержание выбранного и порядок резолверов.
- Отдельный UDP-пул и правила TCP/UDP. Проверки задержки используют HTTPS и не подтверждают доступность UDP.
- До 32 текущих соединений в «Обзоре», без служебных загрузок подписок.
- README, пошаговая инструкция и GitHub Actions обновлены для выпуска 0.3.0.
